# VocXuan

词汇学习软件源码归档。

- `native-v1.6/`：Windows C# 与 Android 源码、构建脚本和既有测试。
- `web/`：网页版源码。

网页版包含 ECDICT 词典及原许可；原生端压缩词典、字体、图片、学习存档、Android 签名材料、账号配置、构建缓存和依赖没有纳入。运行或构建前请按原项目说明补齐资源和环境。词典来源及版本见原项目 dictionary-info.json。本轮通过 Windows 编译、自检、246 项界面断言和 58 项 Android JavaScript / 存档互读检查；手机安装包尚未重新构建。
